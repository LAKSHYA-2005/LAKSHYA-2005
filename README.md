## 🚀 Current Focus

### ⛏️ AI-Enabled Coal Mine Subsidence Monitoring

I'm currently developing an **IoT + AI based mine subsidence monitoring system** designed for continuous monitoring of underground coal mining environments.

The system combines:

**Multi-node sensing → Wireless/Mesh Network → Edge Gateway → Backend & Database → AI/ML → Risk Analysis → Dashboard & Alerts**

The project involves:

* Multi-node sensor architecture
* Continuous structural/environmental parameter monitoring
* Wireless mesh communication
* ESP32-based embedded nodes
* Edge/gateway processing
* Python backend and database
* Node-RED based monitoring dashboard
* AI-based anomaly detection and prediction
* Risk assessment and decision support
* GIS-based visualization
* Power-aware 24×7 operation
* Hardware + software system integration

The goal is not just to collect sensor data, but to build an **end-to-end intelligent monitoring platform** capable of turning raw physical measurements into actionable information.
